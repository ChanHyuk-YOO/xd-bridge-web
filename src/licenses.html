프로젝트 및 라이선스

XD Bridge는 개인이 운영하는 무료 비상업용 베타 프로젝트입니다. Adobe, Figma, FigCraft의 공식 서비스가 아니며 이들 회사·프로젝트와 제휴하지 않습니다. 제품명은 파일 형식과 작업 흐름을 설명하기 위해 사용했습니다.

파일 처리

선택한 파일은 브라우저의 Web Worker와 Python WebAssembly 런타임을 이용하여 처리합니다. 별도의 변환 서버, 파일 저장소, 광고 및 분석 추적 코드를 사용하지 않습니다. 페이지 접속과 정적 프로그램 다운로드에는 호스팅 제공자의 일반 네트워크 접속 기록이 남을 수 있습니다.

변환 품질

레이어·글꼴·이미지·좌표를 가능한 범위에서 변환하지만 모든 XD 구조를 지원하지 않습니다. 결과를 검토하고 원본을 보관하세요. 실험적 FigCraft 직접 출력은 글꼴 메트릭을 근사하며 SVG를 FigCraft가 가져온 결과와 다를 수 있습니다.
